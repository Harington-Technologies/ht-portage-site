Créer mon accès

Utilisez votre adresse professionnelle. L'accès est ouvert dès que votre adresse a été autorisée par l'équipe Harington.

Mot de passe oublié

Indiquez votre e-mail : vous recevrez un lien pour choisir un nouveau mot de passe.

Code de sécurité

Ouvrez votre application d'authentification (Google Authenticator, Microsoft Authenticator…) et saisissez le code à 6 chiffres affiché pour « Pilotage Mecalux ».

Téléphone perdu ou changé ? Demandez à un administrateur de réinitialiser votre double authentification.

Activez la double authentification

Par sécurité, l'accès au pilotage demande un code à usage unique en plus du mot de passe. Installez une application d'authentification sur votre téléphone (Google Authenticator, Microsoft Authenticator…), puis scannez ce QR code.
