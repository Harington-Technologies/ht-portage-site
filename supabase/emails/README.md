# E-mails d'authentification Supabase (charte HT Portage)

Modèles collés dans Supabase › Authentication › Emails › Templates.
Générés à partir du gabarit commun (`supabase/functions/notify-lead/index.ts`, fonction `gabarit`).
Les objets des e-mails sont dans `sujets.json`.

| Fichier | Modèle Supabase |
|---|---|
| confirmation.html | Confirm sign up |
| invite.html | Invite user |
| magic_link.html | Magic link or OTP |
| email_change.html | Change email address |
| recovery.html | Reset password |
| reauthentication.html | Reauthentication |
