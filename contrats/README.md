# Contrats HT Portage

- `modeles/cdi.docx`, `modeles/annexe.docx` : modèles « à remplir » utilisés par la fonction Supabase `contrats` (balises `[[champ]]`, repères de signature Yousign `{{sN|signature|l|h}}` en blanc).
- `generateur/build.js` : génère les modèles. `node build.js` (vierges) puis `MODE=modele node build.js` (à remplir). Après une modification du texte, recalculer les pages du sommaire avec `pages.py`, puis régénérer.

Signataires Yousign : CDI = s1 consultant, s2 HT Portage · Annexe = s1 consultant, s2 client, s3 HT Portage.
