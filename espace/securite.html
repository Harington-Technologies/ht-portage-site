Double authentification.

L'administration donne accès aux données personnelles des consultants (identité, n° de sécurité sociale, IBAN, contrats). En plus du mot de passe, un code à 6 chiffres affiché par votre téléphone est demandé à chaque connexion.

Applications compatibles : Google Authenticator, Microsoft Authenticator, 1Password, Authy…

Activez la double authentification

  1. Ouvrez votre application d'authentification et ajoutez un compte.
  2. Scannez ce QR code avec l'application.
Impossible de scanner ? Saisir la clé à la main
  1. Saisissez le code à 6 chiffres affiché par l'application.

Code de vérification

Saisissez le code à 6 chiffres affiché par votre application d'authentification.
